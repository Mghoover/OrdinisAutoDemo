# ODS Automotive Demo

Canonical automotive repair vertical template for Ordinis Digital Services.

Built from the shared Astro starter with automotive-specific content, SEO page architecture, local search pages, structured data, conversion forms, and reusable data-driven service templates.

## Cloudflare Pages

- Framework preset: Astro
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`
- Node version: `20` via `.node-version`
